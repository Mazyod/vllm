and every external label watchdog independently confirmed teardown. Final

the successful rentals were destroyed only after their releases were published.

The Hopper checkpoint payload is 510,310,568,472 bytes. Its staging resume
reused 307,237,490,896 completed bytes rather than fetching those files again.
The V100 pinned checkpoint payload totals 7,677,982,703 bytes. Each model was
staged once, and serving used offline mode through every process restart.
Network counters measure transport, so they need not equal checkpoint sizes.
The staging intervals can include control and fixture traffic.

Image pulls occur outside guest counters. Earlier Hopper counters were lost
across a container restart, so neither the final counter nor the measured
resume interval is a complete-session transfer total. A complete transfer bill cannot be reconstructed from these counters.

Raw identities, endpoints, transcripts, watchdog logs and billing records remain
in ignored local evidence. These are anonymous test-venue measurements.
